## About CRA

***CRA*** 是面向长春大学，以计算机科学与技术学院为主，多学院联合的致力于机器人竞赛的协会组织。

这里是 ***CRA*** 的 ***GitHub*** 开源工程社区，用于整理和分享：

* **协会资料** —— 机器人协会内部资料
* **技术教程** —— 基础的技术教程
* **算法实现** —— 基础与进阶算法
* **计算机视觉** —— OpenCV、YOLO 等
* **机器人技术** —— 控制算法、集控与创新
* **竞赛项目** —— 机器人项目与比赛成果
