## About CRA

CRA 是面向长春大学计算机技术、电子信息技术与机器人竞赛的协会组织。

这里是协会的 GitHub 开源工程社区，用于整理和分享：

* 📚 **技术教程** —— 基础的学习资料
* 🧠 **算法实现** —— 基础与进阶算法
* 👁️ **计算机视觉** —— OpenCV、YOLO 等
* ⚙️ **机器人技术** —— 控制算法、集控与创新
* 🏆 **竞赛项目** —— 机器人项目与比赛成果
